# 🌍 Global Food Waste Analysis

## 📌 Project Overview
Food waste is a major global issue impacting food security, the economy, and the environment. This project analyzes food waste data from multiple countries to identify patterns, trends, and key factors contributing to food waste across years, countries, and food categories.

---

## 📂 Dataset
- The dataset contains thousands of records from multiple countries.
- It includes the following columns:
  - Country
  - Year
  - Food Category
  - Total Waste (tons)
  - Population (million)
  - Average Waste Per Capita (kg)
  - Household Waste (%)

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Excel
- Power BI (for dashboarding)

---

## 🔍 What Was Done

### ✅ Data Cleaning & Preparation
- Removed null values and checked for duplicates.
- Standardized column names.
- Cleaned country names and formatted numerical columns.

### ✅ Exploratory Data Analysis (EDA)
Created multiple visualizations to understand:

- Country-wise total food waste
- Category-wise food waste distribution
- Year-wise food waste trends
- Average waste per capita by country
- Household waste comparison across countries
- Population vs total waste relationships
- Year and category based heatmap analysis
- Multi-dimensional analysis using scatter plots

---

## 📊 Visualizations Included

- Horizontal bar chart: Country vs total waste
- Pie chart: Food category contribution
- Line chart: Year-wise waste trend
- Bar chart: Household waste comparison
- Scatter plots: Population vs waste & per capita
- Heatmap: Year vs food category waste

---

## 📈 Key Insights

- Certain countries contribute significantly more to total food waste.
- Household food waste forms a major portion in many regions.
- Food waste trends vary noticeably across years.
- Some food categories contribute disproportionately to overall waste.
- Population alone does not fully explain food waste — per capita waste is also an important factor.
